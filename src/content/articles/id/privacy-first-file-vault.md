# Apa itu brankas file yang mengutamakan privasi?

Mo Layer adalah brankas file pribadi untuk iPhone. Aplikasi ini dibuat untuk foto, video, tangkapan layar, identitas, kontrak, tanda terima, tautan, dan file yang tidak seharusnya bercampur dengan media sehari-hari.

## Mengapa tidak cukup memakai album tersembunyi?

Album tersembunyi berguna untuk privasi ringan. Brankas khusus lebih tepat saat Anda membutuhkan organisasi, akses yang tidak mencolok, kategori file, rencana pemulihan, dan batas privasi yang lebih jelas.

## Apa yang dilindungi Mo Layer

- Foto dan video pribadi
- Tangkapan layar sensitif
- Identitas, kontrak, tanda terima, dan dokumen
- File yang ingin ditemukan cepat tanpa bercampur dengan rol kamera publik

## Cara kerja privasi

Mo Layer mengutamakan penyimpanan lokal. Konten Anda tetap berada di perangkat secara default. Jika sinkronisasi iCloud terenkripsi diaktifkan, konten dienkripsi sebelum diunggah dan pengembang tidak memegang kunci dekripsi Anda.

## Apa yang ditambahkan Pro

Pro menambahkan kapasitas, pemulihan, dan kontrol: impor tanpa batas, organisasi massal, sinkronisasi iCloud terenkripsi, penyamaran lanjutan, kontrol umpan, catatan intrusi, dan pemulihan lanjutan.
