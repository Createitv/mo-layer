# Что такое файловое хранилище с акцентом на приватность?

Mo Layer — это личное файловое хранилище для iPhone. Оно предназначено для фото, видео, скриншотов, документов, договоров, чеков, ссылок и файлов, которые не должны лежать рядом с повседневными медиа.

## Почему не просто скрытый альбом?

Скрытый альбом подходит для базовой приватности. Отдельное хранилище лучше, когда нужны организация, незаметный доступ, категории файлов, план восстановления и более четкая граница приватности.

## Что защищает Mo Layer

- Личные фото и видео
- Чувствительные скриншоты
- Документы, договоры, чеки и важные файлы
- Файлы, которые нужно быстро находить, не смешивая их с общей фотопленкой

## Как работает приватность

Mo Layer использует подход local-first. По умолчанию контент остается на устройстве. Если включена зашифрованная синхронизация iCloud, контент шифруется до загрузки, а разработчик не владеет ключом расшифровки.

## Что добавляет Pro

Pro добавляет емкость, восстановление и контроль: неограниченный импорт, пакетную организацию, зашифрованную синхронизацию iCloud, расширенную маскировку, приманки, журналы доступа и расширенное восстановление.

## Частый вопрос

**Сайт хранит личные файлы?**  
Нет. Этот сайт только объясняет приложение, публикует информационные материалы и собирает отзывы о продукте. Это не веб-хранилище.
