# iOS 私密保险箱 App 产品功能方案

## 结论

这个 App 可以做，但不要定位成普通“隐私相册”。更适合定位为“本地优先的私密保险箱”：默认本机加密保存，用户主动开启后才使用 iCloud 同步密文。产品核心不是堆功能，而是让用户相信三件事：内容在哪里、谁能访问、丢手机或换手机后如何恢复。

推荐一句话定位：

> 一个本地加密优先、支持可选 iCloud 加密同步的私密相册与文件保险箱。

## 产品原则

1. 默认本地保存，不默认开启云同步。
2. iCloud 只作为用户主动开启的密文备份/同步能力。
3. 不自建服务器，不上传明文，不做广告追踪。
4. 安全能力必须免费，付费买效率、容量、多设备和恢复能力。
5. 所有敏感操作要清楚解释边界，例如删除系统相册、截图防护、密码恢复。

## 核心使用路径

### 首次使用

- 设置主密码。
- 开启 Face ID / Touch ID。
- 生成恢复密钥。
- 明确提示：如果丢失密码和恢复密钥，开发者无法解密内容。

### 导入内容

- 从系统相册导入照片/视频。
- 从 Files 导入 PDF、文档、音频等文件。
- 支持 App 内拍照/录像后直接进入保险箱。
- 导入完成后提示是否删除系统相册原件，并提醒清空“最近删除”。

### 日常访问

- 打开 App 后 Face ID 解锁。
- 浏览保险箱、文件夹、最近导入、收藏。
- App 切后台自动遮挡内容并锁定。

### 防窥场景

- 后台预览模糊。
- 快速锁定。
- 假密码进入伪装空间。
- 截屏/录屏检测和提醒。
- 解锁失败记录。

### 恢复与迁移

- 本地导出加密备份包。
- 可选开启 iCloud 密文同步。
- 新设备通过密码、恢复密钥或 iCloud Keychain 恢复密钥材料。

## MVP 功能

### 本地加密保险箱

- 照片、视频、文件导入。
- 文件夹分类。
- 收藏、最近导入、回收站。
- 单个导出和批量移动。
- 元数据也应加密保存，包括文件名、相册名、标签、拍摄信息。

### 解锁与安全

- 主密码。
- Face ID / Touch ID。
- 自动锁定。
- 连续输错延迟。
- 后台遮挡。
- 恢复密钥。

### 导入导出

- PhotosPicker 导入照片/视频。
- 文件选择器导入。
- App 内相机直存。
- 分享面板导出。
- 导出前二次验证。

### 备份

- 本地加密备份包。
- 加密备份导入恢复。
- iCloud 同步放到后续版本或 Pro。

## 进阶功能

- iCloud Drive 或 CloudKit 密文同步。
- 伪装首页，例如计算器、文件扫描器、工具箱。
- 假密码 / Decoy Vault。
- 入侵记录，可选失败拍照。
- 私密笔记。
- 私密文件保险箱。
- 高级标签、搜索、批量整理。

## 信息架构

推荐底部导航：

1. 保险箱：全部、照片、视频、文件、文件夹、收藏。
2. 导入：相册导入、文件导入、拍照存入、导入记录。
3. 备份：本地备份、iCloud 同步、恢复数据、同步状态。
4. 安全：解锁方式、自动锁定、伪装模式、防窥设置、恢复密钥、安全日志。

也可以把“导入”做成底部中间主按钮，Tab 保留为：保险箱、备份、安全、设置。

## 不要做什么

- 不做公开分享、在线相册链接、多人协作。
- 不默认开启云同步。
- 不承诺“绝对安全”“永不丢失”“彻底防截图”。
- 不把本地加密、Face ID、基础导出做成付费。
- 不偷偷删除系统相册原件。
- 不做广告和第三方追踪。
- 不做完整密码管理器，避免产品过重。

## 1.0 功能清单

免费版建议包含：

- 本地加密保险箱。
- 主密码和 Face ID 解锁。
- 基础导入照片/视频/文件。
- 文件夹、收藏、最近导入。
- 后台遮挡和自动锁定。
- 本地加密备份导出。
- 恢复密钥。
- 无广告、无追踪。

Pro 版建议包含：

- 无限导入。
- 批量整理。
- iCloud 密文同步。
- 多设备恢复。
- 回收站高级恢复。
- 伪装入口。
- 假密码空间。
- 入侵记录。
- 大视频支持。
