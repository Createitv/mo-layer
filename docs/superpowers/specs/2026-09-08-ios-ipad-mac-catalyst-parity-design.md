# Mo Layer iPhone、iPad 与 Mac Catalyst 功能同步设计

日期：2026-09-08

## 目标

让 Mo Layer 的 iPhone、iPad 和 Mac Catalyst 版本共用同一套业务能力、数据模型、安全规则、会员权限和云同步行为。平台有对应系统能力时保持相同行为；平台缺少对应硬件或系统 API 时提供完成同一用户任务的等价入口，不出现无响应或永久禁用的入口。

本设计中的“功能同步”表示：用户可以在三端完成相同的保险箱核心任务，操作结果和权限判断一致。它不要求 Mac 模拟 iPhone 专属的系统界面，例如主屏快捷操作或 Live Activity。

## 已确认方案

采用现有 Mac Catalyst 目标，不新增独立原生 macOS target。iPhone、iPad 和 Mac Catalyst 继续共享 SwiftUI 页面、SwiftData 模型、加密服务、CloudKit 容器、RevenueCat 会员状态和本地化资源。

平台差异集中在统一的能力与路由层中，业务页面不自行散落 `targetEnvironment(macCatalyst)` 判断。以后新增或修改 iPhone 功能时，必须同时定义 iPad 和 Mac 的路由行为并进入同一测试矩阵。

## 当前基础

- 主应用 target 已启用 iPhone、iPad 和 Mac Catalyst。
- iPad 已支持横竖屏，主页已存在基于常规宽度的分栏布局。
- Mac Catalyst 已存在桌面分栏、工具栏和部分键盘快捷键，当前代码能够完成无签名构建。
- 三端共用保险箱模型、Mo Layer 权限策略、CloudKit 容器和会员管理器。
- 当前平台能力判断会在 Mac 上关闭相机、文档扫描、Live Activity 和主屏快捷操作，但部分界面只留下禁用状态，缺少等价路由或说明。
- 现有测试主要验证共享业务逻辑，缺少明确的 iPad/Mac 功能路由合同与三端运行冒烟覆盖。

## 功能合同

### 共享核心能力

以下能力在三端使用相同实现和权限规则：

- 首次引导、安全码、手势锁、生物识别解锁和会话锁定。
- 普通保险箱与 Mo Layer 的进入、退出、只读和 Pro 权限规则。
- 相册、音频、文件、链接分类，以及收藏、选择、批量操作、删除、移动和恢复流程。
- 图片、Live Photo、视频、音频、文档和文件详情。
- 免费容量限制、Pro 购买、恢复购买、会员状态刷新和购买后权限更新。
- 本地加密存储、缩略图、导入队列、CloudKit 上传下载和冲突状态。
- 外观、语言、安全中心、权限说明、存储用量和隐私政策。

共享能力不得复制为三套业务分支。平台层只决定入口、系统集成和布局表达，最终操作必须调用同一个服务或策略对象。

### iPhone

iPhone 保持当前紧凑布局与移动端能力：

- 相机拍照、录像和 Live Photo 直存。
- VisionKit 文档扫描。
- 照片迁移、文件导入和音频录制。
- Live Activity 显示录音或长任务进度。
- 主屏快捷操作进入导入、相机或录音流程。
- 视频播放时的设备亮度与音量控制。

### iPad

iPad 保留 iPhone 的完整移动端功能，同时适配更大的可用空间：

- 常规宽度使用 `NavigationSplitView`，紧凑宽度回退到单列导航。
- 横屏、竖屏、分屏和 Stage Manager 下不依赖固定屏幕尺寸。
- 导入、会员、设置、预览和编辑弹窗根据可用空间选择 sheet、popover 或全屏表达，但完成动作和返回路径一致。
- 支持外接键盘的刷新、导入、全选和设置快捷键。
- 相机、照片、文档扫描、音频录制和 Live Activity 保持可用。

### Mac Catalyst

Mac Catalyst 使用桌面分栏、工具栏、菜单、键盘和拖放交互，同时保持相同的数据结果：

- 文件导入使用系统文件面板，并正确处理安全作用域资源。
- 照片导入使用可用的照片选择流程；Finder 文件可通过选择器和拖放进入同一导入队列。
- 音频录制在麦克风权限可用时保持原流程。
- 相机或 VisionKit 扫描不可用时，入口改为“导入照片或文件”，并说明这是桌面等价流程；不得显示无法执行的扫描按钮。
- Live Activity 对应为应用内持续进度卡和完成/失败系统通知。
- 主屏快捷操作对应为应用菜单和 `Command` 快捷键。
- 视频亮度调整作用于播放器画面，不修改整个 Mac 显示器亮度；音量仍作用于播放器。
- 兑换码系统面板不可用时，展示 App Store 兑换步骤或打开受支持的系统入口；购买和恢复购买仍使用共享会员管理器。

## 平台能力与路由层

将当前布尔能力集合扩展为可测试的操作路由。每个受平台影响的任务返回明确路由，而不是由页面组合多个布尔值。

建议的路由类型包括：

- 捕获媒体：原生相机、照片/文件替代入口、不可用说明。
- 文档扫描：VisionKit 扫描、照片/文件替代入口。
- 后台进度：Live Activity、应用内进度与通知。
- 快捷入口：主屏快捷操作、Mac 菜单与键盘快捷键。
- 兑换码：系统兑换面板、App Store 引导。
- 播放亮度：设备屏幕亮度、播放器画面亮度。

路由对象必须是纯值类型，可以在单元测试中为 iPhone、iPad 和 Mac 构造确定结果。SwiftUI 页面读取路由后展示正确入口，服务层仍负责实际导入、加密、同步和购买。

## 数据流

### 导入

1. 用户从平台合适的入口选择媒体、文件、录音或扫描结果。
2. 平台适配器将结果规范化为共享导入请求。
3. 免费容量与会员策略在导入开始前统一校验。
4. 共享导入队列读取源文件、生成元数据和缩略图，并写入加密保险箱。
5. Pro 用户按当前规则触发 CloudKit 同步。
6. 三端展示同一种成功、部分成功或失败摘要。

Mac 文件面板返回的 URL 必须在读取期间持有安全作用域访问，并在读取结束后释放。不得为了兼容而降低保险箱加密或文件保护规则。

### 预览与编辑

1. 共享选择状态确定当前项目和相邻项目。
2. 共享保险箱服务解密到受控临时位置或返回内存对象。
3. 平台播放器或预览容器显示内容。
4. 收藏、移动、删除、导出和详情操作调用相同服务。
5. 页面关闭时释放播放器、临时文件和平台资源。

### 会员与同步

1. RevenueCat 刷新会员状态并生成共享访问级别。
2. Mo Layer、导入容量和 CloudKit 写入只读取共享访问级别。
3. 购买或恢复成功后刷新权限和保险箱写入能力。
4. CloudKit 使用相同容器和记录格式；平台不得产生不同版本的数据结构。

## 布局与交互

- 所有主页面以可用容器宽度为准，不直接依赖 `UIScreen.main.bounds` 决定整体布局。
- iPhone 紧凑布局保持当前单列体验。
- iPad 常规宽度使用侧栏、内容和详情；尺寸变为紧凑时保留当前选择并回退单列。
- Mac 使用桌面侧栏和工具栏，支持窗口缩放；关键内容设置合理最小宽度，避免固定为 iPhone 尺寸。
- 所有模态页面必须有明确的关闭路径。导航推入页面使用系统返回；全屏或独立模态使用关闭按钮或取消操作。
- iPad 和 Mac 的鼠标、触控板、键盘焦点与辅助功能标签必须可用；触摸手势不能成为唯一入口。

## 错误处理

- 平台不支持：展示等价入口和简短原因，不抛出通用失败，也不留下死按钮。
- 权限拒绝：说明被拒绝的具体权限，并提供系统设置入口；已经选择的数据不得静默丢失。
- 导入失败：沿用共享摘要，区分不支持格式、权限、读取、加密和同步失败。
- CloudKit 不可用：保留本地内容并显示可重试状态，不能阻塞本地查看。
- 会员加载失败：保留已有访问级别，购买界面可关闭，并提供重试或恢复购买。
- Mac 安全作用域失败：停止该文件导入并报告文件名，不影响队列中其他文件。

## 安全与隐私

- 三端继续使用相同的加密格式、钥匙串策略、CloudKit 容器和 Mo Layer 权限判断。
- Mac 继续启用 App Sandbox，只声明导入、导出、麦克风、照片、CloudKit 和应用组所需权限。
- 不因桌面拖放或文件选择绕过免费容量、Pro 权限或目标文件夹校验。
- 临时解密文件按现有生命周期清理，窗口关闭或任务取消时同样执行清理。
- 生物识别在不同设备上使用系统可用机制，无法使用时回退安全码，而不是降低验证等级。

## 本地化与可访问性

- 新的平台说明和替代入口覆盖现有八种本地化资源。
- 避免写死 “iPhone 设置”；根据平台显示“系统设置”或对应设备名称。
- 图标按钮保留可读的辅助功能标签和状态值。
- Mac 菜单、键盘快捷键和 iPad 外接键盘快捷键不能与文本输入或系统保留快捷键冲突。

## 测试设计

### 单元测试

- 每个平台的能力和操作路由合同。
- 免费容量、会员访问级别和 Mo Layer 入口保持平台无关。
- 相机、扫描、Live Activity、快捷入口、兑换码和亮度的替代路由。
- Mac 安全作用域文件导入的成功、单文件失败和队列继续行为。
- iPad 尺寸类别切换后选择状态和详情状态保持。

### 构建验证

- iPhone Simulator 无签名构建与测试。
- iPad Pro Simulator 无签名构建与测试。
- Mac Catalyst 无签名 Debug 构建与测试。
- Release 配置分别检查 iOS/iPadOS 与 Mac Catalyst 的 entitlements、嵌入扩展和产品设置。

### 运行冒烟

在 iPhone、iPad 和 Mac Catalyst 分别验证：

- 首次引导、锁定和解锁。
- 普通保险箱与 Mo Layer 进入和退出。
- 免费用户 Pro 提示可以返回。
- 导入一张图片、一个视频、一段音频和一个文件。
- 打开、播放、翻页、收藏、移动、删除和导出。
- 会员页购买入口与恢复购买。
- CloudKit 刷新、离线查看和失败重试。

iPad 额外验证横屏、竖屏、二分之一分屏和 Stage Manager 窗口；Mac 额外验证窗口缩放、拖放、菜单、键盘快捷键和硬件功能替代入口。

## 完成标准

- 三个平台的共享功能合同均有明确实现和自动化覆盖。
- iPhone、iPad 和 Mac Catalyst 构建通过。
- 三端运行冒烟没有无法返回、无响应或永久禁用且无解释的入口。
- 核心数据、加密格式、权限和 CloudKit 记录不因平台分叉。
- 平台专属能力均有真实能力或已确认的等价替代，不以隐藏功能冒充同步。
- 当前工作区中的无关改动未被覆盖或混入本任务提交。

## 非目标

- 不创建独立原生 AppKit/macOS target。
- 不让 Mac 模拟不存在的 iPhone 系统界面。
- 不改变现有加密算法、CloudKit 数据结构、免费容量或会员定价。
- 不在本兼容任务中重做品牌视觉或无关页面。
