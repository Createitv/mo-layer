# iOS 私密保险箱 App 会员商业化方案

## 商业化结论

可以商业化，但付费设计必须克制。隐私类 App 不能让用户感觉“不付费就不安全”。免费版必须提供完整基础安全能力，Pro 购买的是无限容量、批量整理、iCloud 同步、多设备恢复、伪装、防窥和高级管理。

核心原则：

> 安全是底线，效率和恢复能力才是付费点。

## 产品分层

| 版本 | 定位 | 功能 |
|---|---|---|
| 免费版 | 建立信任 | 本地加密、PIN/Face ID、基础导入、基础文件夹、有限容量、无广告、无追踪 |
| Pro 月/年订阅 | 持续价值 | 无限导入、批量整理、iCloud 同步、多设备、自动备份、回收站、伪装、入侵记录 |
| Lifetime | 抗订阅用户 | 解锁当前和未来本地 Pro 功能，谨慎承诺云能力 |
| Family Sharing | 年付价值增强 | 共享 Pro 权益，不共享任何私密内容 |

## 必须免费的功能

- 本地加密保存。
- PIN / Face ID 解锁。
- 基础导入照片和视频。
- 基础查看、删除、导出。
- 离线可用。
- 无广告、无第三方追踪。
- 数据位置透明说明。
- 恢复密钥和密码丢失风险提示。
- 删除 App / 删除保险箱前的清晰警告。
- 恢复购买入口。

## 适合 Pro 的功能

- 无限照片、视频、文件数量。
- 批量导入、批量选择、批量移动。
- iCloud 密文同步。
- iPhone / iPad / Mac 多设备访问。
- 自动备份和恢复。
- 最近删除 / 回收站。
- 大视频支持。
- 高级文件夹、标签、搜索。
- 伪装图标和伪装入口。
- 假密码 / Decoy Vault。
- 入侵记录。
- 私密浏览器下载到保险箱。
- App 内相机直存保险箱。
- 家庭共享购买。

## 推荐定价

| 产品 | 美国价格 | 中国区价格 | 目的 |
|---|---:|---:|---|
| Pro Monthly | $3.99/月 | ¥18/月 | 低门槛 |
| Pro Yearly | $19.99/年 | ¥98/年 | 主推 |
| Lifetime | $39.99-$59.99 | ¥198-¥298 | 抗订阅 |

早期建议：

- 主推：¥98/年，7 天免费试用。
- 月付：¥18/月，不给试用。
- 买断：¥198 早鸟，稳定后 ¥268 或 ¥298。

## 试用策略

推荐 7 天免费试用，仅用于年订阅。

原因：

- 隐私 App 需要用户导入真实数据后才感知价值。
- 3 天太短。
- 14 天容易降低付费紧迫性。
- 7 天足够体验导入、整理、同步、恢复。

## Paywall 结构

标题：

> 让你的私密内容更安全，也更容易恢复

副标题：

> 免费版已包含本地加密。Pro 解锁无限空间、多设备同步、自动备份和高级隐私工具。

卖点：

- 无限保存。
- iCloud 密文同步。
- 误删恢复。
- 批量整理。
- 伪装保险箱。
- 家庭共享。

底部信任文案：

> 免费版可继续使用本地加密保险箱。订阅可随时在 App Store 取消。

## App Store 订阅文案

订阅标题：

- Pro 私密保险箱
- 年度 Pro 会员
- 终身 Pro

订阅描述：

> 升级 Pro，解锁无限私密存储、批量导入、多设备同步、自动备份、回收站恢复、高级伪装与更多隐私管理功能。你的内容默认保存在你的设备和个人 iCloud 中，我们不会查看、出售或用于广告追踪。

订阅说明：

> 订阅将通过你的 Apple ID 付款，并在到期前自动续订。你可以随时在 App Store 账户设置中管理或取消订阅。免费试用结束后将按所选方案自动续订。

## 转化路径

不要首屏强弹订阅。推荐触发点：

1. 用户创建保险箱成功后展示“本地加密已开启”，不卖。
2. 导入 20-50 张后轻提示 Pro 可批量整理。
3. 达到免费容量上限时展示付费页。
4. 点击 iCloud 同步时展示 Pro。
5. 点击自动备份或误删恢复时展示 Pro。
6. 使用 3 天后展示年付试用。

## Lifetime 边界

Lifetime 可以包含：

- 无限本地保险箱。
- 无限导入。
- 高级文件夹和标签。
- 伪装入口。
- Decoy Vault。
- 批量整理。
- 当前版本本地 Pro 功能。

不要承诺：

- 终身无限云存储。
- 终身所有服务器功能。
- 终身所有未来服务。

如果未来没有自建服务器，只使用用户自己的 iCloud，可以把 iCloud 同步纳入 Lifetime，但文案要写清楚依赖用户自己的 iCloud。

## 避免的坑

- 免费版不要加广告。
- 不要用“军用级加密”“绝对安全”。
- 不要在导入前强制订阅。
- 不要把 Face ID、本地加密、导出变成付费。
- 不要偷偷上传用户内容做 AI 分类。
- 不要默认开启云同步。
- 不要频繁弹付费页。
- 不要隐藏取消订阅说明。
