# 隐私伪装保险箱 App 设计稿说明文档

## 1. 设计稿目标

本文档用于指导 `Palimpsest` 的 iOS 视觉设计、页面设计和组件落地。设计方向不是“私密相册”，而是“普通文件工具外观下的加密保险箱”。第一眼要像工具，第二层才是安全产品。

## 2. 设计关键词

- 普通工具感
- 本地归档
- 低暴露
- 克制安全感
- 行为入口
- 可信诱饵
- 清晰整理
- 私密但不暧昧

## 3. 视觉方向

### 3.1 总体气质

界面应该像 iOS 上一个干净、专业、可信的文件归档工具。真实保险箱内部可以出现更明显的安全状态，但仍然保持克制，不做黑客风、霓虹风、保险柜拟物风。

### 3.2 色彩

| Token | 颜色 | 用途 |
| --- | --- | --- |
| Background | `#F6F8FB` | App 背景 |
| Card | `#FFFFFF` | 卡片、列表容器 |
| Ink | `#111827` | 标题和主文字 |
| Secondary | `#667085` | 次要文字 |
| Line | `#E5E7EB` | 分割线、描边 |
| Primary | `#2563EB` | 主按钮、选中态 |
| Accent | `#14B8A6` | 已加密、安全状态 |
| Warning | `#F59E0B` | 建议处理 |
| Danger | `#DC2626` | 删除、永久清空 |

使用规则：

- 伪装层尽量少用锁、盾牌、强安全色。
- 真实层可以使用青绿色表达“已加密”。
- 红色只用于删除和高风险警告。
- 不使用大面积渐变。

### 3.3 字体

- 字体：SF Pro / 苹方。
- 大标题：28-34 pt，Semibold 或 Bold。
- 页面标题：20-24 pt，Semibold。
- 分区标题：15-17 pt，Semibold。
- 正文：14-16 pt，Regular。
- 辅助文字：12-13 pt，Regular。
- 数字和容量：可使用 monospaced digit。

### 3.4 圆角与间距

- 页面左右边距：16-20 pt。
- 卡片圆角：8 pt。
- 缩略图圆角：6-8 pt。
- 按钮圆角：8 pt。
- 分区间距：20-24 pt。
- 组件内间距：12-16 pt。

避免过度圆润的大胶囊风格。

## 4. 页面设计稿清单

### 4.1 S01 首次引导页

#### 目标

解释产品机制，但不暴露真实内容。

#### 页面结构

```text
+------------------------------------------------+
|                                                |
|  [folder / archive icon]                       |
|                                                |
|  Welcome to Palimpsest                         |
|  It looks like a file archive. Your encrypted  |
|  private vault opens only with the correct     |
|  gesture.                                      |
|                                                |
|  [Disguised file tool]                         |
|  [Gesture entry]                               |
|  [Encrypt on import]                           |
|  [Decoy vault]                                 |
|                                                |
|  [ Set Up Palimpsest ]                         |
+------------------------------------------------+
```

#### 设计要求

- 使用文件夹 / 归档图标，而不是保险柜。
- 文案短，用户能快速读完。
- CTA 固定在内容底部或安全区域上方。

### 4.2 S02 手势设置页

#### 目标

建立真实入口。

#### 页面结构

```text
+------------------------------------------------+
|  Set entry gesture                             |
|  Draw a gesture you can remember.              |
|                                                |
|  +------------------------------------------+  |
|  |                                          |  |
|  |          Gesture drawing area            |  |
|  |                                          |  |
|  +------------------------------------------+  |
|                                                |
|  [progress: 1 / 3]                            |
|  [ Continue ]                                  |
+------------------------------------------------+
```

#### 状态

- 初次绘制。
- 二次确认。
- 相似度不足。
- 设置成功。

#### 注意

- 手势区要足够大，至少 240 pt 高。
- 不显示手势轨迹保存结果。
- 错误提示用普通提示，不用红色大警告。

### 4.3 S03 备用安全码页

#### 目标

设置固定 6 位备用码，用于重设手势。

#### 页面结构

```text
+------------------------------------------------+
|  Create security code                          |
|  Use 6 digits to reset your gesture if needed. |
|                                                |
|      [ _ ] [ _ ] [ _ ] [ _ ] [ _ ] [ _ ]       |
|                                                |
|  This code cannot directly open the vault.     |
|                                                |
|  [ Finish setup ]                              |
+------------------------------------------------+
```

#### 状态

- 空输入。
- 输入中。
- 位数不足。
- 确认成功。

### 4.4 S04 伪装首页

#### 目标

默认看起来像普通文件工具，并承载隐藏手势入口。

#### 页面结构

```text
+------------------------------------------------+
|  Files                                         |
|                                                |
|  +------------------------------------------+  |
|  | Local Archive                  [folder]  |  |
|  | 28 files · Offline storage               |  |
|  | [iPhone] Local   [Tray] Archived         |  |
|  +------------------------------------------+  |
|                                                |
|  +------------------------------------------+  |
|  | [hand / organize icon] Quick organize    |  |
|  | Drag here to sort recent files           |  |
|  +------------------------------------------+  |
|                                                |
|  Recent files                                  |
|  [PDF] Project Notes.pdf        2.4 MB         |
|  [IMG] Receipt Scan.jpg        812 KB          |
|  [ZIP] Archive-2026.zip        18 MB           |
+------------------------------------------------+
```

#### 关键设计点

- 隐藏手势区伪装为整理工具卡片。
- 正确手势进入真实保险箱。
- 错误手势进入诱饵空间。
- 不出现“错误”“失败”“密码错误”。

## 5. 组件规范

### 5.1 AppCard

- 背景：白色。
- 圆角：8 pt。
- 描边：`#E5E7EB`。
- 阴影：极轻，或不用阴影。
- 内边距：14-16 pt。

### 5.2 StatusPill

- 高度：28-32 pt。
- 图标：SF Symbols。
- 文本：12-13 pt。
- 用于状态，不用于主操作。

### 5.3 PrimaryButton

- 高度：48-52 pt。
- 圆角：8 pt。
- 背景：`#2563EB`。
- 文本：白色 Semibold。
- Loading 状态保留按钮宽度。

### 5.4 FileRow

- 左侧：文件类型图标。
- 中间：文件名、日期。
- 右侧：大小或更多操作。
- 高度：56-64 pt。
- 支持滑动操作，但危险操作需确认。

### 5.5 ThumbnailGrid

- 手机竖屏：3 列。
- iPad 或横屏：4-6 列。
- 间距：4-8 pt。
- 缩略图比例：1:1。
- 支持隐藏缩略图模式，占位图为文件类型图标。

### 5.6 GestureArea

- 最小高度：80 pt，用于伪装首页隐藏入口。
- 设置页高度：240-320 pt。
- 触摸反馈：轻微高亮，不展示完整轨迹。
- 完成后立即判断并清空临时点。

## 6. 交互动效

| 场景 | 动效 |
| --- | --- |
| 进入真实保险箱 | 轻微淡入，180-240 ms |
| 进入诱饵空间 | 普通导航切换，不出现错误反馈 |
| 导入完成 | 文件缩略图淡入或列表插入 |
| 锁定 | 内容淡出，回到伪装页 |
| 删除 | 收缩消失 + 确认弹窗 |
| 订阅成功 | 简洁成功态，不放烟花式动效 |

## 7. 空状态与错误状态

### 7.1 真实保险箱空状态

标题：No private files yet  
说明：Import photos, videos, or files to encrypt them on this device.  
按钮：Import

### 7.2 诱饵空间空状态

诱饵空间不应为空。即使用户没有配置，也应展示内置拟真文件。

### 7.3 导入失败

标题：Some items could not be imported  
说明：Show count and reason. Do not expose internal paths.  
按钮：Try again / View imported

## 8. 本地化注意事项

- 英文优先保持工具感。
- 中文避免“神器”“防查岗”“秘密基地”等低信任词。
- 德文、法文、西班牙文按钮文字较长，按钮必须支持换行或动态宽度。
- 安全码、文件大小、日期跟随系统地区格式。

## 10. 设计验收清单

- 伪装首页第一眼像普通文件工具。
- 伪装首页不出现隐私保险箱关键词。
- 错误手势进入诱饵空间时没有错误提示。
- 诱饵空间可点击、可浏览、不空。
- 真实保险箱入口明确但不暴露给旁观者。
- 真实保险箱内导入、浏览、整理效率不低于普通相册。
- 安全中心不是装饰页，所有状态可理解。
- 所有危险操作都有二次确认。
- 小屏设备文字不截断。
- 深色模式对比度合格。
- 多语言长文本不溢出。
- App Store 截图不夸大安全能力。

- 03 Cover Shell

- 05 Decoy Vault

- 09 Settings

每个页面至少交付：

- 默认状态。
- 空状态。
- Loading 状态。
- 错误 / 风险状态。
- 深色模式。
- 中文和英文两版关键页面。
