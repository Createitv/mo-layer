# iOS 私密保险箱 App 设计风格方案

## 设计结论

建议做成“专业级个人隐私保险箱”，而不是黑客风、保险柜拟物风或暧昧私密相册。可以参考钉钉的清爽秩序感和高效工具感，但不要照搬蓝白视觉。这个 App 的气质应该是：冷静、可信、克制、专业、可控。

设计关键词：

- 加密感
- 安全感
- 克制
- 专业
- 清爽秩序
- 高效工具
- 低干扰
- 可信赖
- 隐私边界
- 冷静掌控

## 视觉方向

界面应该像一个“安全控制台”，而不是普通相册。照片内容是主角，但系统始终传达“已加密、已保护、可控”的状态。

推荐使用：

- 细线。
- 低饱和冷色。
- 清晰分区。
- 状态标识。
- 权限提示。
- 加密徽章。

避免：

- 赛博朋克。
- 大量黑底绿字。
- 霓虹扫描线。
- 过度拟物保险柜。
- 粉紫暧昧风。

## 颜色

推荐色板：

- 主色：`#2563EB` 或 `#1D4ED8`，用于主按钮、选中状态、关键安全提示。
- 深色安全色：`#0F172A`，用于标题、深色锁屏背景、加密状态页。
- 背景色：`#F7F9FC`，保持清爽工具感。
- 卡片色：`#FFFFFF`。
- 辅助青色：`#14B8A6`，用于“已加密”“同步安全”等正向状态。
- 警示色：`#F59E0B`，用于风险提醒。
- 危险色：`#DC2626`，仅用于删除、清空、入侵记录等高风险操作。

整体不要满屏蓝色。蓝色只做操作引导和安全状态，主体保持白、灰、深蓝文字。

## 字体

使用 iOS 系统字体：苹方 / SF Pro。

建议层级：

- 页面标题：20-24pt，半粗体。
- 分区标题：15-17pt，中等字重。
- 正文说明：14-15pt，常规字重。
- 辅助信息：12-13pt，低对比灰色。
- 数字信息：可使用系统数字风格，增强工具感。

文案要短、明确、可信：

- 已加密保护
- 私密空间已锁定
- 最近访问
- 安全检查
- 隐藏入口
- 伪装密码

避免：“你的秘密由我守护”这类情绪化文案。

## 图标

使用细线、圆角、几何感强的线性图标。建议统一线宽 1.75px 或 2px。

图标方向：

- 锁
- 盾牌
- Face ID / 指纹
- 文件夹
- 图片
- 眼睛关闭
- 云端锁
- 警报
- 时钟记录
- 私密标签

不要使用可爱图标、3D 保险柜、金属门和复杂旋钮。

## 布局

推荐结构：

1. 顶部安全状态。
2. 核心内容。
3. 快捷操作。
4. 底部导航。

首页可以包含：

- 顶部状态：“已加密保护”“Face ID 已启用”。
- 快捷入口：“导入照片”“拍照存入”“新建文件夹”“安全检查”。
- 内容网格：3 列或 4 列缩略图，圆角 6-8px。
- 底部 Tab：保险箱、导入、安全、设置。

不要做营销首页。用户打开 App 应该直接进入可操作的私密空间。

## 核心页面

### 解锁页

目标是建立第一眼信任。

元素：

- 极简品牌名。
- 中央锁形标识。
- 文案：“私密空间已锁定”。
- 主按钮：“使用 Face ID 解锁”。
- 次入口：“输入密码”。

不要显示缩略图、文件名、数量明细。

### 保险箱首页

顶部显示：

- 保险箱。
- 已加密保护。
- 内容数量，例如“248 项私密内容”。
- 安全状态徽章。

中部分类：

- 私密照片。
- 私密视频。
- 文件。
- 收藏。
- 最近导入。

支持“模糊预览”或“隐藏缩略图”模式。

### 导入页

导入入口要直接：

- 从系统相册导入。
- 拍照存入。
- 扫描文件。
- 从文件导入。

导入后给明确选择：

- 导入后从系统相册删除。
- 仅复制到保险箱。
- 完成后提醒我手动删除。

### 安全中心

这是专业感核心页面。建议做成状态清单：

- Face ID 状态。
- 密码强度。
- 伪装入口。
- 入侵记录。
- 最近解锁记录。
- 云同步加密状态。
- 自动锁定时间。
- 隐藏 App 内容预览。

每一项显示“已开启”“建议开启”“存在风险”。

### 设置页

结构：

- 账户与订阅。
- 解锁方式。
- 自动锁定。
- 隐私保护。
- 数据备份。
- 帮助与反馈。
- 关于。

订阅入口不要强压，放在“高级保护”或“Pro 功能”中。

## 动效

动效要稳，不要炫。

- 解锁：轻微模糊解除 + 内容淡入。
- 加密完成：锁图标闭合。
- 导入完成：缩略图轻微收纳进入保险箱。
- 删除：确认后收缩消失。
- 安全检查：轻扫扫描线或进度条。

动效时长控制在 180-320ms。

## 设计禁区

- 不做黑客风。
- 不做暧昧风。
- 不照搬钉钉蓝白布局。
- 不用夸张圆角和大卡片堆叠。
- 不在锁屏页暴露任何内容。
- 不使用过亮荧光色或大面积渐变。
- 不让危险操作太容易触发。
- 不把安全中心做成装饰页，它必须是真正可操作的控制面板。
