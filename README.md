## What Mo Layer Does

Mo Layer helps iPhone users protect and organize private photos, videos, screenshots, IDs, contracts, receipts, links, and important files. It uses a local-first privacy model, supports optional encrypted iCloud sync for recovery and device changes, and keeps private content inside the iPhone app rather than on the website.
